## 常见答辩问题

**为什么分析 Agent 不调用模型？** AST 适合准确提取签名和结构，语言模型负责文档表达与独立语义审查；三个节点使用统一接口和消息协议。

**Agent 怎么协作？** 分析发 analysis_ready，文档发 draft_ready，审校发 approved 或 revision_requested；编排器读取共享状态并决定下一步。

**怎么恢复失败？** 每个节点都有持久化检查点。重试时跳过 succeeded 节点。代码语法错误需要修正源码并新建任务，网络暂时失败可以直接恢复。

**如何证明真实调用？** 展示 trace 中文档和审校输出的 llm 字段：提供商、服务返回的模型、请求 ID、token usage；其中不包含 API Key。

**哪里可扩展？** 实现统一 run 接口加入节点列表即可；当前反馈分支针对 writer/reviewer，复杂图和后置门控需要扩展编排器。
